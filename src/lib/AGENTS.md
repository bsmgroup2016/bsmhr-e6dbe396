- A worker's own direct portal check-in/check-out is written server-side with the service key, scoped to the employee resolved from the caller's token and limited to time/GPS fields, because the connected RLS grants workers no attendance writes.
- Direct self punches preserve original times through conditional writes and read-back; checkout derives hours from the shared duty rule, never from client-supplied totals.
- Auth event callbacks defer session-dependent queries until after the session lock releases, preventing sign-in/refresh deadlocks.
- Media mutations require server-verified admin access, target only the selected bucket, verify object writes/deletion and protect claim-template files; manual uploads preserve the scans/main split and register only small metadata.
- Browser role reads share bounded transport retries and fail closed with explicit recovery; failed reads are not empty role assignments, and stale results cannot cross account identities.
- Dormitory billing uses dedicated relational invoice/payment tables and a locked, caller-authorized RPC; immutable idempotent payments prevent duplicate and excess payments, while fixed admin-only setup enables only the checked-in billing migration.
- Chatbot replies and training share staggered, cancellable provider hedging; complete valid responses win without changing saved priority, and assistant rounds retain tool results and prefer their last successful provider to avoid repeated slow lookups.
- Removed OCR readers are rejected in shared provider resolution, including Settings tests. Active time-card dispatch uses consensus with enabled Settings key overrides: router first, mandatory native Gemini, then flagged-only OpenAI; deterministic checks adapt into existing claim rows without unverified fallback.
- Time-card jobs use owner/source-checked stable ids, conditional R2 creation and ETag claims to prevent paid replay; main R2 holds results while sessionStorage holds only job/source references. Bounded read-only polling and automatic same-tab recovery tolerate dropped connections, but browser-independent completion needs an approved durable runner, not waitUntil.
- Targeted OCR rows run in ordered groups of three only after router and mandatory Gemini; denials and rate limits pause later groups and preserve human-review flags rather than replaying requests.
- Excel AI analysis is a separate workbook: the AI returns only an allowlisted plan (pivots/threshold/notes); software writes formulas with cached results and blocks export when totals disagree, so AI cannot alter hours or pay.
